# JitGen Examples

This directory contains example projects demonstrating how to use JitGen for incremental code execution.

## Examples

### 1. Basic Usage (`basic_usage.py`)

Demonstrates the core JitGen functionality with a simple code stream. Shows how code fragments are executed incrementally as they're generated.

### 2. LangChain Integration (`langchain_example.py`)

Shows how to integrate JitGen with LangChain to execute code generated by LLMs incrementally.

### 3. Interactive Calculator (`interactive_calculator.py`)

An interactive example that simulates an LLM generating calculator code, demonstrating real-time execution and output.

## Running the Examples

```bash
# Basic usage
python examples/basic_usage.py

# LangChain integration (requires Ollama or compatible LLM)
python examples/langchain_example.py

# Interactive calculator
python examples/interactive_calculator.py
```

## Requirements

- Python 3.13+
- JitGen installed (run `uv sync` from project root)
- For LangChain example: Ollama or compatible LLM API
